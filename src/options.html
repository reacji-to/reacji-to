Your reactions. Your choice.

Any emoji on dev-null, X, and LinkedIn. Keep it private or share it on your reacji.to profile.

Connect to GitHub

Connect once to react in one click. GitHub will show you a short code to approve—no personal access token to create or paste.

Your token is stored inside this extension and sent only to GitHub and reacji.to to verify your account. GitHub authorization expires and renews automatically; the sites you react on never receive your token.

Enter this code on GitHub, then approve dev-null reactions.

Keep this settings tab open. It will connect automatically after you approve. Never approve a code you didn’t request.

Your private reactions

Choose a private repository owned by your GitHub account. The app needs Contents: read and write on that repo only.

On GitHub, select Only select repositories. If creating a repo, choose Private, then install the app on it. Return here and refresh the list.

What happens when you react

  1. Choose Public or Private in the emoji picker.
  2. Your reaction is tied to your GitHub identity. On dev-null, your signed-in account must match.
  3. The reacji.to Worker commits data/[platform]/<post-id>.json to the shared public repo or your selected private repo.
  4. Public reactions appear on reacji.to/YOUR_GITHUB_HANDLE and in other users’ pickers.

One reaction per account per post in each visibility mode. Public and Private are separate; switching does not move or erase an existing reaction. Pick another emoji to change it, or choose your current reaction again to remove it.

Public reactions and their history are public. Private reactions stay in your private GitHub repo; its collaborators, GitHub, and the app service can access them. They never contribute to public counts. Removing a reaction updates current data, but does not erase Git history.
