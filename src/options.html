        Private repository backup

        Choose a private repository owned by your GitHub account. Each local change is copied there when possible. Local reactions continue working if the backup is unavailable.

        On GitHub, select Only select repositories. If creating a repo, choose Private, then install the app on it. Return here and refresh the list.

        What happens when you react

        1. Hold down Option (Alt on Windows/Linux) and click page content, or use the eyes beside a post.
        2. Start typing immediately, then choose any emoji or one of your labels.
        3. The reaction stays in this browser. A configured Raycast or Slack rule runs only for its mapped emoji.
        4. If you configured a private repository, the extension also attempts a backup after each local change.

        Reactions reattach when their saved target can be matched. If a page changes too much, the pin stays hidden. Browser settings pages and other extension-restricted pages cannot have reactions.

        Where your reacji live

        Reactions, labels, and Raycast mappings live in this browser’s extension storage. They are not published to reacji.to or a shared GitHub repository.

        Webpage reactions include the URL, placement details, and a short visible text excerpt so they can appear in the same spot later.

        A private repository backup is optional. Git history in that repository remains visible to its owner and collaborators.
