Whose reactions you see

Your own reactions always stay visible. This filters what you see; your Public reactions remain public. The following list uses your connected GitHub handle and refreshes every five minutes.

Connect to GitHub

Connect once to react in one click. GitHub will show you a short code to approve—no personal access token to create or paste.

Your token is stored inside this extension and sent only to GitHub and reacji.to to verify your account. GitHub authorization expires and renews automatically; the sites you react on never receive your token.

Enter this code on GitHub, then approve reacji.to.

Keep this settings tab open. It will connect automatically after you approve. Never approve a code you didn’t request.

What happens when you react

  1. Hold Option (Alt) and click page content. You can also right-click and choose 👀 reacji to this, or use the eyes beside a post.
  2. Choose Public or Private in the emoji picker.
  3. Your reaction is tied to your GitHub identity. On dev-null, your signed-in account must match.
  4. The Worker commits your emoji to the public data repo or your selected private repo. Web placements also save the page URL, element path, position, and a short visible text excerpt.
  5. Public reactions appear on reacji.to/YOUR_GITHUB_HANDLE and on the page for other extension users.

Reactions reattach when their saved target can be matched. If a page changes too much, the pin stays hidden. Browser settings pages and other extension-restricted pages cannot have reactions.

Where your reacji live

Reacji are saved as commits in GitHub. Public reacji and their history are visible to everyone in our public repository ↗.

Private reacji live in your chosen private repo, accessible only to you and any collaborators you may have invited.

GitHub hosts your data, and the app has permission to read and write your reactions. We check that your repository is private before saving.

Reacji on webpages also save the page URL, placement details, and a short text excerpt so they can appear in the same spot later.

Removing a reacji removes it from view, but doesn’t erase its Git history.
