Any emoji. One reaction.

A smiley beside every star. Your reactions live in a public Git repository, shared with everyone using this extension.

Connect to GitHub

You can react without a token: choose an emoji, then submit the prefilled issue in GitHub. For one-click reactions, connect a personal access token.

For this shared public repository, use a classic token with public_repo. That scope also grants access to your other public repositories. Fine-grained tokens only work if they have Issues: write access to this repository.

Create a classic token on GitHub ↗

Otherwise the token lasts for this browser session. It is accessible only to the extension and sent only to GitHub, never to dev-null.sh.

What happens when you react

  1. The extension opens a reaction issue under your GitHub account.
  2. GitHub Actions updates data/<post-id>.json and creates a commit.
  3. Other extension users fetch the file directly from GitHub.

One reaction per account per commit. Pick another to change it, or choose your current reaction again to remove it. GitHub processing and caching can delay shared counts.

Reactions, usernames, and submissions are public. Removing a reaction updates the counts; the previous reaction remains in Git history and its issue.
