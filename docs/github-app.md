# GitHub App and Worker setup

The website and Worker now live in [reacji-to/reacji-to-web](https://github.com/reacji-to/reacji-to-web). See its [setup guide](https://github.com/reacji-to/reacji-to-web/blob/main/docs/github-app.md).

Install the organization-owned `reacji-to` GitHub App on **only reacji-to/reacji-to-data** for public reactions. It needs Contents read/write and mandatory Metadata read. The extension and website source repositories do not need app installation.
